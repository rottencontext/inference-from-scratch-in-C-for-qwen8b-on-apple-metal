The map and the limit

Which C function uses which part of the machine, and why 7.3 tokens per second is already close to what this design can do.

Bytes pulled from RAM for one generated token

MLP 20.3 GBattention 5.6 GB2.3
gate, up, down: 3 × 192 MB × 36 layersq, k, v, o: 160 MB × 36 layersoutput layer, 2.3 GB

No matrix fits in a cache. The largest are 192 MB and the L2 is 16 MB, so every weight is fetched from RAM again for every token.

How close to the memory limit the engine already runs

This is arithmetic from the benchmark, not a measurement of this Mac's real memory speed. If it holds, six cores doing float32 math are not the bottleneck. The path to RAM is.
